# Focused prior-art and implementation review

Reviewed 2026-11-16. The candidate is an attributed, deliberately small baseline, not a claim of novelty. No external implementation was copied.

| Work | Source-reported mechanism and evidence | Code, compute, license, and model scope |
|---|---|---|
| [RMA for manipulator arms](https://www.robots.ox.ac.uk/~vgg/publications/2024/Liang24/) | Action/proprioceptive history and depth condition adaptation to hidden properties; ManiSkill2 manipulation tasks. | [Code](https://github.com/yichao-liang/rma4rma) revision `2f938f6518709ac8cbda05c294b7765c6d16630d`; author README calls for CUDA and reports one A100. Inspected `models.py`: separate privileged and adapter features; task-specific dimensions and training commands. Results should not be assumed one shared model across all tasks. GitHub did not report a repository license; reuse terms unverified. |
| [In-Context World Modeling](https://arxiv.org/abs/2606.26025v3) | v3: short self-generated, task-agnostic interaction history conditions a world model for novel configurations without weight updates; simulation and physical camera-view results. | This is a close conceptual overlap, particularly in-context system inference. Paper method: five random contact-free probing transitions are prepended to the task query and share the VLA backbone; evaluation includes four LIBERO suites and four real tasks. Authors report Qwen2.5-VL-3B, training on 8 A100 GPUs and latency on one RTX 4090. Code/checkpoint license and whether one checkpoint covers every task remain unverified; paper is a preprint. |
| [ASID](https://weirdlabuw.github.io/asid/) | Optimizes exploration for Fisher information, fits simulator parameters and subsequently trains task-specific policies. | [Code](https://github.com/WEIRDLabUW/asid) revision `cf2cb670fb983f67cf2af156d4e17b4a690787e2`; README uses MuJoCo, SB3, Python 3.9 and CUDA 11.8/12.3; authors report 32+4 workers on 64 GB. Repository license not verified. The page explicitly separates exploration from task-specific policies; not a shared deployment model claim. |
| [Poke and Strike](https://marina-aoyama.github.io/poke-and-strike/) | CoRL 2025 learns exploration with reward derived from task-policy sensitivity and uses uncertainty to switch to action. Includes striking and edge-pushing examples. | The project page lists a code entry but did not provide a linked repository in the inspected page; license, compute, and whether tasks share weights are unverified. This is direct prior art for task-relevant information gathering. |
| [TD-MPC2](https://github.com/nicklashansen/tdmpc2) | Predictive planning using a learned latent model, including both single-task and a shared multitask 80-task model. | Revision `332f19e4aba4bffe2dc736f45ea7f7bdc585903a`, MIT. Inspected `tdmpc2.py`: encoder, dynamics, rewards, value and GPU planning. README recommends 8 GB GPU for small workloads and 24 GB for its 317M model; not suitable for a direct port to this pilot's 6 GB GPU. |
| [SuperMimic](https://github.com/HybridRobotics/supermimic) | One differentiable world model for a humanoid whole-body tracker; not manipulation adaptation evidence. | Revision `5f69628350940d7eb1968184eda449b3d8d18b8d`, Apache-2.0. README uses mjlab and CUDA; specific compute and cross-task shared-parameter evidence are not established by the README. |

Our inference: a fixed-window, small observable-dynamics model and bounded receding-horizon selection form a practical local baseline, not a reproduction of any paper above. Task-relevant disagreement and dual-control ideas overlap substantially with ASID, Poke and Strike and classical dual control; do not assert novelty from combining those ingredients. Neither generic information gain nor ensemble disagreement establishes task value. ICWM and RMA already make history-based adaptation central.

Selective background: [RL²](https://arxiv.org/abs/1611.02779) explicitly represents fast adaptation with recurrent state, while [Feldbaum's dual-control work](https://www.mathnet.ru/php/archive.phtml?jrnid=at&option_lang=eng&paperid=12624&wshow=paper) predates these learned approaches. ICWM's paper page links a CC BY-NC-ND 4.0 publication license; this is not an asserted license for any implementation.
