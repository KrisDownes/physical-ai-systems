# Integrated calibration and motion adaptation

## Existing gripper self-calibration

The previous self-calibration fixes camera intrinsics (320×240 image, 45° vertical field of view), camera height 0.7 m, optical orientation, and nominal camera x/y origin. It estimates only a two-dimensional camera translation. One detected cyan marker pixel supplies two image coordinates; the controller uses joint encoder readings and nominal forward kinematics to calculate the assumed 3D marker position, including the fixed marker-to-gripper geometry. With marker height, camera orientation and intrinsics assumed correct, projecting the detected pixel to the assumed marker height yields a nominal world position; subtracting it from the assumed FK marker position gives the translation correction. A single observation cannot independently recover camera rotation, depth, general 3D translation, or an unknown marker mounting offset. Missing marker detection gives no estimate. Encoders give joint angles, not measured physical tool or marker position: the estimate additionally assumes accurate link lengths, joint zeros, rigid mounting and marker placement.

The table recalibrator detects two fixed, known magenta reference locations on the table, assumes their height and nominal camera model, and estimates the same restricted 2D translation. Its object projection assumes the box top is at z=0.04 m and its destination projection assumes the marker is at z=0.002 m. These assumptions, a stationary overhead camera during a trial, visible features, and the fixed grasp alignment limit the result. Simulator camera transforms and changed tool parameters are evaluator-only; the controller accesses only rendered pixels, joint readings and its unperturbed nominal FK.

## Tool uncertainty and observability

The disturbance is a rigid displacement `[dx,0,0]` in the parent **wrist frame** of the gripper body. It moves the physical fixed jaw, moving jaw, nominal tool site and visible gripper marker together. The marker-to-tool relationship within the rigid gripper body is unchanged. The controller's separate nominal model assumes the original zero wrist-to-gripper mounting offset, including both nominal tool position and nominal marker position. Neither joint readings nor nominal FK reveal the applied offset directly. It is not a camera-only or marker-only change.

With a valid table estimate, the difference between table- and gripper-derived translation corrections exposes a projected inconsistency, but one view alone does not determine the full 3D mounting offset. If table references are absent, a camera translation and a projected tool/marker offset can produce the same observed pixel displacement at one pose. Different arm orientations can make their predictions differ, but this controller does not yet use a multi-view estimator or execute a diagnostic probe. Joint-command response RLS cannot independently identify a rigid tool mounting offset from encoder readings alone.

## Controller components

All methods use the same rendered image, encoder readings, task controller, limits and episode budgets. The fixed and motion-only conditions use the nominal camera calibration. Calibration-only and integrated use exactly the same selector: prefer two table references only if their translation estimates agree within 6 mm and the estimated shift is within 40 mm. If valid table references disagree with the gripper-marker correction by more than 4.5 mm, reject the gripper correction and use the table estimate. A consistent gripper estimate is also logged but table still takes priority. If table references are absent, use a bounded gripper estimate as a fallback, explicitly assuming nominal geometry. If detected table references disagree with each other, do not silently switch to the gripper: reject the calibration and fail the episode. Accepted/rejected sources and reasons are recorded.

After the selected calibration is applied, object and destination positions are both reprojected from their detected initial pixels. A change in calibration increments a coordinate epoch; joint-command response RLS is retained because its input and output are joint increments, whereas a Cartesian residual map, if present, is invalidated. This experiment performs one calibration at the beginning of each independent trial; it does not claim to implement within-episode camera-change detection. The calibration-only and integrated methods use the same selector and target construction; motion-only and integrated use the same `OnlineJacobian`. Adaptation state is reset at the start of each trial. Its accepted/rejected updates, reasons and matrices are logged; it does not use the actual geometry disturbance or simulator truth.

## Existing online/fixed discrepancy

The archived `heldout-a` shifted-camera case had identical initial observations and target for fixed and online control. Their first command matched. On the second action, the online RLS update changed the command by 0.00098 rad in norm; by the eighth action the tip trajectories differed by 1.35 mm. At the end of reaching their tool sites were within approximately 0.83 mm of one another, but their joint postures differed. During closure the online trajectory pushed the object away and the jaw reached -0.1 rad with no grasp; fixed stopped at +0.115 rad against the object. These deterministic traces show contact sensitivity to the different adapted trajectory; they do not isolate a single physical cause within contact dynamics.

The first online update used the bounded command and the immediately observed encoder change, matching the RLS pairing. An implementation inconsistency was found in command construction: the learned joint-response matrix was applied to the translational Jacobian but not to the pitch constraint. Both rows now use the same response matrix, with a regression test. On replay of this previously inspected case the unchanged fixed controller and corrected online controller both succeeded (82 and 83 actions). This makes the inconsistency a plausible contributor; contact sensitivity and other changes made while adding the separate nominal model prevent claiming it was the sole cause. The fitted response still includes servo transients, position tracking error, saturation and nonlinear contact; it is not an exact static motor gain. The numerical comparison and corrected replay are separate recorded runs, not new held-out evidence.
